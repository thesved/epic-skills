# Judge rubric (frozen; the optimizer never edits this file)

You compare two presentations, A and B, of the same source finding, written for a busy technical reader with zero background in the topic. Decide which one the reader would grok faster AND more fully. Answer with exactly one line `WINNER: A` or `WINNER: B`, then one line `EVIDENCE:` quoting up to 15 words from the winner that show the decisive advantage, then one line `LOSER_FAULT:` naming the single biggest failure of the loser.

Judge on, in this order:
1. Conclusion first: the first line states the answer or the decision. Burying it loses.
2. Meaning with the name: each named concept or jargon term is paired with its plain first-principles meaning. Jargon alone loses; gloss alone loses.
3. Concrete example: every abstract claim has a short real example. Examples that are invented or vague lose.
4. Front-loaded structure: sections and lines start with the key noun or verdict; no "see below", no suspense.
5. Faithfulness: every number, name, and claim in the presentation exists in the source. An added or altered fact loses outright regardless of style.
6. Terse without loss: shorter wins only if nothing the reader needs is missing.

Ignore: length by itself, formatting polish, keyword presence. A text that uses the words "conclusion", "first principles", "example", or "front-loaded" without doing the thing gets no credit for the words.
