# Meta Muse Spark 1.3 (meta/muse-spark-1.3 via OpenRouter)

Researched 2026-09-05 (three days after release). Ids/pricing: `../openrouter.md`. Evidence: `../research/2026-09-05/` (5 codex lanes, 180 YouTube reports, live probes, 3 bakeoffs). Tags: `[off]` Meta/OpenRouter official, `[com]` community, `[us]` measured by us on 2026-09-05.

## What it is

Meta Superintelligence Labs' proprietary flagship: Spark 1.1 (2026-07-09), Spark 1.2 + the Muse Code CLI (2026-08-05), Glimmer 30B open weights (Apache 2.0, 2026-08-10, distilled from Spark, small local model, not covered here), **Spark 1.3 (2026-09-02)** `[off]`. 1,048,576 context, 943,718 max output, input text + image + video + PDF + audio, text out, reasoning mandatory, single upstream (Meta), 18+ attestation required on OpenRouter (Meta's terms require API users to be 18+). Open weights for Spark "coming", no date `[off]`.

Price `[off]`: **$1.25 in / $4.25 out / $0.15 cache read**, web search $2.50 per 1K calls. **Contributor tier $0.10 / $0.20 / $0.002 = the same model, but "Prompts and outputs may be used to improve Meta's products"**, and Meta's archived terms forbid sensitive, confidential or personal data on it. Our OpenRouter account blocks it ("Paid model training violation (account settings)"), same guardrail that blocks DeepSeek first-party; lifting it is a data-policy decision, not a config fix.

## Route to / away

**TO it** `[us]`: (1) **recall-critical long-context text reads**: 293K-token needle 3/3 in 15 s for $0.37 at effort low, official MRCR 98.1 at 512K-1M vs Sol 73.8; the cheapest 1M seat with strong recall we have. (2) **PDF and MP4 (with sound) reading without Google**: both worked first try through OpenRouter. (3) **Bounded implementation and single-pass frontend or 3D prototypes** where a spec exists: 11/11 on our 11-task bakeoff at every effort, textwrap-exact 60/60 and 55/60 (Sol 57/60, Gemini 3.7 Flash 43/60, Luna 8/60), repo bugfix through our mini agent 11/11 in 6 turns at low ($0.023, Sol high $0.048, Gemini 3.8 Flash thrashed 28 turns for $0.16). (4) Opt-in board seat for Meta-family diversity.
**AWAY** `[com+us]`: UI taste and polish (every hands-on video: below Fable 5.1, "rougher, less cohesive"); long multi-turn autonomous runs (Stone Labs Q3 Close 8/100, KingBench 71 vs 76 for Spark 1.2, plan drift, premature "done", full-file rewrites for one-line edits); anything private on Contributor; audio (official: "not fully supported", WAV is silently dropped, see below); YouTube URLs (400); the Codex CLI harness (below); sole reviewer or truth arbiter (original Muse sycophancy 58-63%, 11% false refusals on benign cyber prompts `[off, system card]`); security seat.

## Drive it

- **Effort** `[us]`: `low` for tool loops and bounded work, default (medium) for exact-spec coding, `xhigh` only when correctness beats time. 9-task set: low = default scores at half the wall and cost (93 s, $0.109 vs 177 s, $0.149), xhigh same scores at 606 s, $0.245. Hard textwrap-exact task: low 37/60 and 57/60, default 55/60 and 60/60, xhigh 60/60 twice but 5-6 min per call (22-28K reasoning tokens); agentic repo fix: low 11/11 in 26 s, xhigh 11/11 in 190 s, and xhigh threw two 'Provider returned error' failures on the 6-call tool loop that low and default never hit. Official values minimal/low/medium/high/xhigh, documented default medium; `max` = "Contemplating" mode, limited preview after safety testing `[off]`; OpenRouter accepts `max` without error but there is no proof it serves Meta's max. Reasoning cannot be disabled (`effort: none` and `enabled: false` both 400 "Reasoning is mandatory"). Traces are hidden except a one-line summary at xhigh; keep `reasoning_details` in the message history across tool turns.
- **Tools and schema** `[us]`: strict `json_schema` (integer fields, enums, nested arrays) 9/9; 6-call tool loop with pagination and an error-hint retry 3/3 on two runs; parallel tool calls fine. Meta direct only supports `tool_choice: auto` `[off]`; via OpenRouter `tool_choice` passes through untested.
- **Media shapes through OpenRouter** `[us]`: image `image_url` data URI ok. Video: `video_url` with `data:video/mp4;base64,...` or a `file` part with the mp4 both work and the audio track is heard; a YouTube URL returns 400 "unsupported media type text/html. Supported: MP4" (Gemini remains the YouTube route). Audio: `input_audio` with `format:"mp3"` works; `format:"wav"` is **silently dropped** (the model says it sees no audio); `m4a` 400; audio inside a `file` part is ignored. PDF as a `file` part (data URI) works, 2.5K tokens for a one-page memo.
- **Cost control**: no explicit cache_control; count a hit only when `usage.prompt_tokens_details.cached_tokens` says so. Reasoning is billed as output and consumes `max_tokens`. 85-150 tok/s, 2-8 s for short answers, 60-190 s when it reasons 7-20K tokens on a hard function.
- **Availability**: sole upstream; 95% three-day availability at launch, 503s under load `[off+com]`. Retry with backoff, keep a fallback seat.
- **Harnesses** `[com]`: OpenCode (free "Zen" contributor tier, OpenCode Go $10/month), Hermes Agent, Meta's own Muse Code CLI (`--ultra` for max reasoning, `--yolo` to skip approvals), Meta Model API `https://api.meta.ai/v1` with cookbook configs for Claude Code and OpenCode. Practitioners hit "stream closed before a finish_reason" on chat completions with Spark 1.2; pin the Responses transport where the harness allows. **Codex CLI cannot drive Spark** `[us]`: `wire_api = "chat"` was removed in Codex 0.153, and over `responses` Meta's endpoint rejects Codex's tool set with 400 "`name` must be at most 64 characters, got 66" even with apps, goals, multi-agent and web search off; use OpenCode/Hermes/own loop instead. Claude Code via OpenRouter's Anthropic-compatible gateway is officially "may not work correctly" for non-Anthropic models.
- **Prompting** `[com, 33 hands-on videos + threads]`: a frozen implementation contract (routes, mechanics, viewport limits, build check) gave five first-prompt builds with zero build errors, "AAA quality" wording gave primitive output; screenshots dropped into the loop fix visual bugs it cannot see otherwise; budget wall time before escalating (xhigh on a large codebase: 6 cycles, ~1 h); physics, CAD dimensions, collisions and camera math need a human or a test, it inverts them silently; give it the plan (a stronger model's design doc) and a bounded brief with an exact deliverable, stop condition and blocked condition; it oscillates between conflicting priorities instead of reconciling them; ask for targeted diffs, not whole-file rewrites; keep commits small and review every diff; vague "AAA quality" prompts fail, explicit mechanics succeed.
