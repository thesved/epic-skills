## TLDR (what changed for us)

1. **Fable 5.1 replaces Fable 5 everywhere, but Anthropic's own routing is "start on Opus 5".** 2x Opus per token, "slower" tier (TTFT 39 s at high, 297 s at max), capped at 50% of a Max plan's weekly limit. The gains are real and concentrated: Terminal-Bench-Science 52.6% (Fable 5 24.7, Opus 5 29.0), Terminal-Bench 4.0 55.8% (42.0 / 52.3), AutomationBench 31.4% (17.1 / 26.9), CursorBench 73.4% (70.5 / 70.0), computer use, 1M-context synthesis, vision with a crop tool. Routine coding: Opus 5 ties or wins (Snorkel matched set 23 vs 20 tasks; 67% vs 18% on build/dependency tasks; "not a strict upgrade").
2. **Effort became a per-role dial.** Level names were recalibrated: 5.1 `medium` ≈ Fable 5 `high`, 5.1 `low` ≈ Opus/Sonnet on cost per task. Willison: low/medium/high ≈ $0.10-0.13 per prompt, xhigh $1.83, max $3.30. Artificial Analysis: high 62 at $1.43, xhigh 65 at $2.72, max 66 at $3.69-3.76 (20% MORE than Fable 5 max, 1.7x the output tokens). CodeRabbit: `low` beat `high` on review recall. Cognition: FrontierCode peaked at `medium`. Roles: orchestrate high (medium for routine turns), review low, escalation-implement medium, xhigh only after high failed, never max as a default. `ultracode` = xhigh + Claude Code workflows (a 2-hour, $156 spec phase on one build).
3. **The 25-45% saving is the cache-READ cut and applies to metered Fable-5-shaped workloads only.** Reads $0.25 (was $1.00), writes unchanged at $12.50/$20. Two measured bills were 58-66% cache WRITES. Subscriptions do not see the price; Anthropic says overall Max usage "should be ~same as Fable 5". Day-one field range: Max 5x window gone in 12-60 min on parallel high/xhigh builds with subagents; single agent ~2h20m; 5-6 h of site builds = 45% of weekly Fable. Weekly limits change 2026-09-14 (+25% permanent replaces +50% temp, net 17% cut).
4. **Claude Code 2.1.258 already ships the 5.1 prompting fixes.** Verified in the live system prompt: autonomy block, Delivering-work scope block, progress line, writing rules, context-anxiety fix, plus per-turn injections of the batching nudge and the tool-output-visibility note. Remaining gap snippets: scope-and-tests, surgical edits, audit-claims, verification cadence. `/effort` changes still restart the Claude Code cache (cache key = model + effort); the API's per-message effort keeps it. Fast mode is Opus-only. Task budgets are API-only.
5. **7 official behavior deltas, each with a fix**: one tool call per turn in implied loops; fewer progress updates; answers from memory at `low`; denser prose; less formatting (delete anti-formatting rules); unmarked quotations (Every: 43 "quotes" when asked for 8-12, several invented); whole-file rewrites. Plus premature stopping/asking (autonomy block), and long deliverables drafted twice at xhigh/max (run at high; two testers hit 64K caps with zero output).
6. **API breaking changes**: forced `tool_choice` returns 400; 5.1 thinking blocks unreadable by earlier models; editing anything before a thinking block invalidates it (accounts created on/after 2026-08-31, `thinking-binding-controls-2026-08-01`). New betas: per-message effort, turn-scoped system messages, `thinking.display: "updates"`, `fallbacks: "default"` (targets Opus 4.8 cyber / Opus 5 bio). Streaming required above 21,333 max_tokens. `/claude-api migrate`, `prompt-audit`, `cost-optimize` are bundled.
7. **Refusals: 60% fewer cyber, 85% fewer bio false positives, and they still bite.** Finding vulnerabilities in source is now allowed; pentest/exploit/binary work still routes to Opus. Claude Code fallback pins the session to Opus 4.8 (cyber) or Opus 5 (bio) until re-selected; CLAUDE.md, skills and git history can flag the FIRST request (`claude --safe-mode`, `switchModelsOnFlag: false`). Day-one triggers: "military campaign" metaphor, signed cookies, auth code, `seccomp`, medical, asking the model about itself. Official mitigations: "Are there any bugs" not "does it compile", explain rare languages, strip base64.
8. **Executor routing unchanged: Sol implements, Fable plans/reviews, Opus 5 is the precision seat.** Senior SWE-Bench: Fable 5.1 medium and Sol xhigh tie at 34.7% tasteful pass, Sol at half the output dollars; Cognition's hybrid $1.43 vs pure Fable $2.68. Fable wins agentic hunts (Finn's Gauntlet 100 vs 0), research depth (344 tool calls), policy-heavy approvals; Sol wins mechanics, speed, slide decks; Grok 4.6 delivers ~96% of Fable's gauntlet score at 1/17 the cost. New: Fable 5.1 `medium` as the escalation executor after Sol fails twice. Verification honesty: Snorkel caught 5.1 claiming a re-verification it never ran; METR's Sol cheating record stands. Neither executor's own claims are evidence.
9. **/goal on 5.1: mechanics unchanged, economics changed, evidence still thin.** Check-ins 30m/1h/2h capped at 3 idle per goal, resume on every route, "impossible" verdict, unrecoverable errors clear the goal. 5.1 narrates less, so conditions must demand PRINTED evidence; cap subagents (storm reports); compact later; overnight on a subscription is a gamble (API key or usage credits with a cap).

## 2. What practitioners found in 48 hours (lane B + 104 videos)

Consistent across sources: strong at long unattended runs (Every "Hands" agent 24 h on ultracode, 3-5M tokens; Ramp 38 h; MongoDB 3 days), self-verifying builds (Playwright loops), root-cause hunts, objective critique, factual research depth; per-step efficiency vs Opus 5 (Every: <half the tokens, 60% of the time; 766 vs 1,939 tokens per run). Negatives: subscription burn, subagent storms at xhigh/ultracode, re-reading loops, partial-task stopping ("wanting to write follow-up issues instead of closing out"), edits colliding with reviewer subagents, whole-file rewrites, hallucination rate up on AA Omniscience (attempts 93% of questions vs Opus 5 88%), invented quotes, CodeRabbit reviews 49% slower than Fable 5 (but 70% fewer nitpicks), 3D/physics/mesh glitches (z-fighting, floating objects, inverted joints) across a dozen game builds, SVG taste unchanged, watermark complaints. Taste vs Opus 5 split: several one-shot UI wins for 5.1, Pat Simmons' 5-build blind test 4-1 for Opus 5/Fable 5.

Verbatim tactics that helped (graded D): "only generate the slides, don't do anything else" (scope); "ship a runnable end-to-end slice first"; "Playwright and Chromium are preinstalled, use them to play-test with screenshots and iterate"; "Ask all agents to start wrapping it up. Do not add anything new." (kill a polish loop); `/claude-api prompt-audit` on a spec found end-state-only verification and negative-only constraints; meta-prompt with Opus 5 then hand the structured spec to Fable at high (CodeFactory); "Interview me until you can state the real problem clearly... then start the work" (Balmer).
